## Futures data

Futures use the Massive Futures REST API. Create an API key at
[massive.com/futures](https://massive.com/futures), copy `.env.example` to
`.env`, and configure:

```dotenv
FUTURES_PROVIDER=massive
FUTURES_API_KEY=your_massive_api_key
```

The Futures Basic plan is sufficient for development contract discovery and
delayed aggregate candles. Real-time snapshot entitlement depends on the
Massive plan. The application falls back to the latest real aggregate bar for
quotes and never substitutes spot commodity prices for futures contracts.
